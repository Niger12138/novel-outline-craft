> L1 结构层。填完本文件并获确认后，才展开卷纲与细纲。
> 凡标 `【必填】` 的区块不可留空；留空会被 `scripts/check_outline.py` 报出。

---

## 一句话梗概 【必填】

- **一句话**：（谁 + 在什么处境下 + 想做什么 + 最大阻力 + 赌注是什么）
- **差异化卖点**：（同类题材里，读者只能从这本书拿到的那个东西；1-3 条）
- **目标长度**：约 ______ 万字 / ______ 卷 / ______ 章，单章 ______ 字

## 故事引擎 【必填】

- **引擎**：这本书靠什么持续产出事件？（如：身份错位带来的连锁反应 / 不断升级的追捕 / 每卷新开的势力博弈）
- **循环**：一轮引擎如何运转（触发 → 主角行动 → 反噬 → 升级），一轮大约几章
- **为什么跑得住**：引擎至少能撑过前 ______ 章而不重复

## 核心冲突 【必填】

- **贯穿全书的核心矛盾**：
- **对立面**：（不是"反派是谁"，而是"什么力量在持续反对主角"）
- **不可调和的点**：（为什么双方不能各退一步了事）

## 红线自检（写完逐条确认）

- [ ] 前 3 章内主角已遇到第一次真正冲突
- [ ] 前 10 章内核心班底/关键关系成形
- [ ] 每一卷都有明确卷末兑现点，不是"过渡卷"
- [ ] 所有伏笔都写了计划回收位置

## 去 AI 味自检（结构字段零容忍）

- [ ] 全文没有 ban 词：命运的齿轮 / 宿命感 / 不禁 / 不由自主 / 下意识 / 与此同时 / 内心深处 / 五味杂陈 / 意味深长 / 气氛变得 / 空气中弥漫 / 不知不觉
