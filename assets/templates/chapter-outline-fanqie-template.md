# 第N卷 逐章细纲（番茄档位）

> L4 结构层 · 番茄小说风格。本卷范围：第 ______ 章 ~ 第 ______ 章。
> 除了标准四字段，番茄档位额外要求「开篇抓手」与「本章爽点」。
> 字段名请勿改写，`scripts/check_outline.py` 会按 `style.json` 自动加严校验。

---

## 番茄档位本章纪律

- 单章 2000–3000 字（隐形底线 1800，上限 3500）
- 前 300–500 字出本章冲突；每 500–800 字一个爽点；每 1000 字一个小钩子
- 章末必留钩子，且钩子类型不与上一章重复
- 「本章事件」用短句写，单句不超过 25 字，一句话说清谁做了什么
- 情绪靠动作和对话，不写大段心理与环境

## 字段填写规范（番茄档位）

| 字段 | 硬性要求 |
|---|---|
| 开篇抓手 | 写清本章前 300 字要抛的冲突，必须是具体事件 |
| 本章事件 | 一句话，含"谁 + 做了什么 + 结果"；短句，禁情绪与气氛 |
| 本章爽点 | 必填 `类型=`（打脸 / 逆袭 / 身份曝光 / 暴富 / 碾压 / 收服 / 复仇 / 护短 / 甜 / 系统奖励）+ `兑现=` 写具体兑现方式。类型不得连续 3 章重复 |
| 本章变化 | 四选一（局面/权力/关系/认知），写清变化前后差异 |
| 出场人物 | 至少 2 个（独角戏章除外），标出关系压力；人物须已在 characters.md |
| 场景分解 | 每场齐备 `【目标】` `【阻碍】` `【变化】`；无变化的场景删掉或合并 |
| 伏笔 | `埋 F-00X` / `收 F-00X`，与 ledger.json 编号一致；无则 `埋 —；收 —` |
| 章末钩子 | 必写 `类型=`（八类之一）+ `内容=` 具体事件；类型不得连续 2 章重复 |
| 目标字数 | 1800–3500 之间，默认 2500 |

## 番茄档位钩子纪律

- 章末必钩，无一例外
- 钩子类型不得连续 2 章重复
- 每 5 章内至少覆盖 3 种类型
- 禁反问句、感叹句、总结句、抽象感受词（意味深长 / 不安 / 微妙 / 复杂 / 说不清）

## 去 AI 味硬规则（两档通用）

1. 每个字段必须能落到具体动作。把"本章事件"念一遍，念完手上还是空的，就是没写。
2. "本章变化"必须命中局面 / 权力 / 关系 / 认知 之一。
3. 禁平均：章标题不连章同构、爽点类型不连章重复、钩子类型不连章重复。

ban 词（任一字段出现即不合格）：命运的齿轮 / 宿命感 / 不禁 / 不由自主 / 下意识 / 与此同时 /
内心深处 / 五味杂陈 / 意味深长 / 气氛变得 / 空气中弥漫 / 这一刻他终于 / 他明白了 / 不知不觉。

文青词（番茄档位额外告警）：氤氲 / 斑驳 / 缱绻 / 旖旎 / 怅然 / 恍惚 / 疏离 / 徜徉 / 岑寂 / 萧索 / 迷离 / 苍茫。
