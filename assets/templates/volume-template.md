---

## 本卷任务 【必填】

- **一句话任务**：主角在本卷要达成什么 / 要摆脱什么
- **起点局面**：开卷时主角处于什么状态
- **终点局面**：卷末时局面变成什么（必须与下一卷起点衔接）
- **最大障碍**：本卷持续给主角制造麻烦的力量或人
- **本卷的代价**：主角为达成任务必须失去/付出什么

## 卷内起伏 【必填】

| 段 | 章范围 | 内容 | 张力（1-10） |
|---|---|---|---|
| 起 | | 建立本卷目标，第一次受挫 | |
| 转 | | 假胜利或假失败，赌注抬升 | |
| 合 | | 卷末高潮与清算 | |

- **卷末高潮**：具体发生什么（不是"大战一场"，而是谁做了什么、局面怎么翻）
- **卷末钩子**：留给下一卷的悬念

## 爽点与压抑配比 【必填】

- **小爽点**：约每 ______ 章一次，本卷共 ______ 次
- **中大爽点**：本卷第 ______ 章、第 ______ 章
- **压抑段**：第 ______ 章 ~ 第 ______ 章，压抑多久开始还款
- **节奏原则**：压抑不可连着超过 ______ 章不给回报
