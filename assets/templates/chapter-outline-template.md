## 字段填写规范

| 字段 | 硬性要求 |
|---|---|
| 本章事件 | 一句话，含"谁 + 做了什么 + 结果"，必须有具体动作。禁止只写情绪或气氛 |
| 本章变化 | 四选一（局面/权力/关系/认知），必须写清变化前后的差异 |
| 出场人物 | 至少 2 个（独角戏章除外），标出本场关系压力类型；人物须已登记在 `characters.md` |
| 场景分解 | 每场必须齐备 `【目标】` `【阻碍】` `【变化】` 三标记；无变化的场景删掉或合并 |
| 伏笔 | 用 `埋 F-00X` / `收 F-00X` 标注，与 `ledger.json` 编号一致；无则写 `埋 —；收 —` |
| 章末钩子 | 必须写 `类型=`，八种之一：危机 / 悬疑 / 反转 / 信息 / 情感 / 时间 / 选择 / 生存；内容写具体事件 |
| 目标字数 | 阿拉伯数字，单位为字 |

## 钩子纪律

- 连续 3 章不得使用同一钩子类型
- 每 5 章内至少覆盖 4 种钩子类型
- 禁止用反问句、感叹句、总结句作章末钩子
- 钩子内容禁止出现抽象感受词：意味深长 / 不安 / 微妙 / 复杂 / 说不清

## 去 AI 味硬规则（结构字段零容忍）

1. 每个字段必须能落到具体动作。把"本章事件"念一遍，念完手上还是空的，就是没写。
2. "本章变化"必须命中局面 / 权力 / 关系 / 认知 之一，命中不了的章等于没推进。
3. 钩子不许用抽象感受词（同上）。
4. 禁止平均：章标题不连章同构、张力不连章相同、钩子类型不连章重复。

ban 词（任一字段出现即不合格）：命运的齿轮 / 宿命感 / 不禁 / 不由自主 / 下意识 / 与此同时 /
内心深处 / 五味杂陈 / 意味深长 / 气氛变得 / 空气中弥漫 / 这一刻他终于 / 他明白了 / 不知不觉。

对照表与完整清单见 `references/anti-ai-outline.md`；机检由 `scripts/check_outline.py` 执行。
