# 番茄小说风格模块

本模块把「大纲/细纲」整体调向番茄小说（免费+算法推荐）的内容风格：**小白文、爽点密、钩子多**。

它与 `anti-ai-outline.md` 是两件事：那个模块管"别像 AI 写的"，本模块管"像番茄读者爱看的那种"。两者不冲突，可以叠加。

> 说明：以下数值来自番茄官方帮助中心与行业通行的平台适配经验，平台规则会调整，实际以作家助手后台与当期榜单为准。用法是"当默认值用，不当铁律背"。

---

## 一、平台基因：为什么番茄必须这么写

| 维度 | 番茄的实际情况 | 对写作的硬约束 |
|---|---|---|
| 分发 | 算法推荐，免费阅读，广告变现 | 完读率直接决定推流；读者划走就是数据死亡 |
| 读者 | 18-35 岁学生与打工人，碎片时间，来解压 | 不懂伏笔耐心，不吃文艺调，要即时满足 |
| 生死线 | 前 3 章完读、前 30 章留存；8-10 万字进首秀池 | 开篇没有慢热的资格 |
| 更新 | 断更流量清零，日更 4000 字是基本盘 | 结构要能支撑稳定日更，不能章章纠结 |

一句话概括番茄的底层逻辑：**快、爽、贴**——节奏快、爽点密、贴当下热点题材。

## 二、可量化硬指标（档位默认值）

| 指标 | 数值 | 说明 |
|---|---|---|
| 单章字数 | **2000–3000 字**，隐形底线 1800 | 官方硬底线 1000、上限 50000；首秀期建议 2200–3000 |
| 开篇冲突 | **前 300–500 字必须出核心冲突** | 第一屏内亮出主角处境与危机 |
| 金手指亮相 | **第 1 章内** | 系统/重生/空间/异能，不许拖到第 3 章 |
| 爽点密度 | **每 500–800 字一个爽点** | 3000 字一章约需 4–6 个爽点节点 |
| 小钩子 | **每 1000 字一个** | 段末或场景切换处留 |
| 章末钩子 | **每章必留，无一例外** | 钩子类型不得连续 2 章重复 |
| 爽点节奏 | **3 章一小爽，10 章一大爽，20 章一重大反转** | 前 10 章必须完成第一次打脸或收获 |
| 情绪空窗 | **不得超过 1500 字无情绪波动** | 连续平铺＝劝退 |
| 对话占比 | 尽量高，动作与对话承担叙事 | 禁大段心理活动与环境描写 |

## 三、黄金三章（番茄版）

| 章 | 必须完成 |
|---|---|
| 第 1 章 | 前 300 字抛出强冲突（死亡威胁 / 背叛现场 / 异常现象）→ 锚定主角身份 → 亮出金手指 → 章末悬念 |
| 第 2 章 | 用金手指完成**第一次小逆袭**：打脸一个具体的人，或拿到一个具体的资源，爽感必须兑现 |
| 第 3 章 | 确立一个**清晰的短期目标**（读者知道接下来要看什么），章末埋更大的钩子 |

前三章禁止：世界观说明、势力分布介绍、修炼/职级体系罗列、上千字的背景铺垫。

写法上的通用原则：**冲突前置，背景后置**。背景不删，但要拆成碎片，塞进人物对峙的间隙里。

## 四、爽点工程

### 爽点类型库（写「本章爽点」时从这里选）

| 类型 | 长相 |
|---|---|
| 打脸 | 被轻视的人当场亮出实力，围观者改口 |
| 逆袭 | 从必输局面翻盘，且翻得有据可依 |
| 身份曝光 | 隐藏的马甲被当众揭开 |
| 暴富 / 暴资源 | 突然获得能改变处境的物或钱 |
| 碾压 | 实力差被直观展示，对手毫无还手之力 |
| 收服 | 敌人或强者归附，主角阵营扩张 |
| 复仇 | 对具体加害者的当场清算 |
| 护短 / 团宠 | 主角或其人被集体维护 |
| 甜 | 关系推进，情感兑现 |
| 系统奖励 | 金手指给出实质奖励 |

### 爽点三条纪律

1. **爽点要有"具体受益者与具体损失者"**——打脸要写出谁被打、被打成什么样。
2. **爽点要结账，不能白捡**——每次碾压写清代价、后手或反噬，否则读者会腻。
3. **爽点类型要轮换**——连续 3 章同类型爽点，读者会脱敏。

### 压抑的作用

压抑不是为了虐，是为了抬爽点。番茄式的压抑有两条硬限制：

- 单次压抑不超过 3-5 章，且必须明确写出"多久开始还款"
- 主角不能连续两章纯挨打；挨打时必须同时在积累东西（情报、把柄、人脉、资源）

## 五、钩子工程（番茄加严版）

在标准八类钩子（危机/悬疑/反转/信息/情感/时间/选择/生存）基础上加三条：

1. **章末必钩**，没有例外
2. **钩子类型不得连续 2 章重复**（标准档位是 3 章，番茄更严）
3. **每 5 章内至少覆盖 3 种类型**，且钩子内容必须是具体事件

禁止的钩子：反问句、感叹句、总结句、"意味深长"式抽象描写、"欲知后事"式说书腔。

## 六、语言与段落规范

番茄是手机竖屏阅读，排版本身就是风格：

| 项 | 要求 |
|---|---|
| 句子 | **短句为主**，单句尽量不超过 25 字；超长句拆开 |
| 段落 | **短段，1-3 行为主**，一段一个信息点 |
| 词汇 | 口语化、平实，不用生僻字与成语堆砌 |
| 描写 | 禁大段环境描写；环境只写与当前冲突相关的两三笔 |
| 心理 | 禁大段内心戏；情绪用**动作与对话**外化 |
| 视角 | 第三人称限知，紧贴主角，少切视角 |

情绪外化对照：

| 不番茄 | 番茄 |
|---|---|
| 他感到一阵屈辱 | 他笑了笑，把那张欠条撕了，扔回对方脸上 |
| 她心里很委屈 | 她没说话，低头把碗洗完了，指节捏得发白 |
| 气氛凝重 | 没人说话。有人把烟摁灭在茶几上 |

### 文青词告警表（番茄档位建议清掉）

```
氤氲 / 斑驳 / 缱绻 / 旖旎 / 怅然 / 恍惚 / 疏离 / 徜徉
岑寂 / 萧索 / 迷离 / 苍茫 / 缄默 / 跋涉 / 逡巡
```

这些词不是禁用词，但在番茄档位里出现频率高，通常说明这段在"写文学"而不是"写剧情"。

| 频道 | 高热赛道 | 核心引擎 | 标配爽点 |

| 男频 | 都市战神 / 赘婿逆袭 | 隐藏身份逐层揭开 | 打脸、身份曝光 |
| 男频 | 系统流 / 签到流 | 金手指持续产出 | 系统奖励、碾压 |
| 男频 | 玄幻脑洞 / 无敌流 | 主角一开始就强，看别人反应 | 碾压、打脸 |
| 男频 | 末世囤货 / 规则怪谈 | 信息差与资源差 | 暴富、破局 |

| 女频 | 虐渣打脸 / 重生逆袭 | 复仇与翻盘 | 复仇、打脸 |

选题判断的实操方法：连续 3 天看番茄榜单前 50，找自己的题材在哪个位置。**学它的开局结构与节奏，绝对不要抄情节。**

## 八、书名与简介

| 项 | 要求 |
|---|---|
| 书名 | **15 字以内**，直白点明主角身份或核心剧情，带 1 个热搜词（重生 / 系统 / 末世 / 囤货 / 逆袭 / 战神 / 马甲），不生僻、不文艺 |
| 简介 | **150 字以内**：主角困境 → 金手指 → 最终目标，最后一句留悬念 |
| 章标题 | 直白点出本章事件或爽点，不玩隐喻 |

书名简介决定点击率，在番茄的权重远高于其他平台——大纲阶段就要定死。

## 九、改写对照：文艺向 → 番茄向

同一个情节，两种写法。番茄化的动作是：**把"感受"改写成"事件"，把"铺陈"改写成"当场"，把"渐变"改写成"台阶"**。

| 文艺向大纲 | 番茄向大纲 |
|---|---|
| 主角在家族中饱受冷眼，逐渐意识到自己的处境 | 第 1 章岳父当众摔了他的饭碗，第 2 章他掏出对方求了三个月的那份合同 |
| 两人的关系在相处中慢慢升温 | 第 5 章她替他挡了一巴掌，第 6 章他把她哥的欠条拍在桌上 |
| 主角历经磨难终于获得认可 | 第 8 章验收会上他一句话点破对方方案漏洞，甲方当场换人 |
| 这一卷写主角的成长与蜕变 | 这一卷：拿下城南铺子、收服老朝奉、把崔良逼出京城 |

判据：把这一节大纲念给一个没看过的读者，他能不能在 10 秒内说出"这一节爽在哪"？说不出 → 还没番茄化。

## 十、番茄档位交付检查清单

大纲层：

- [ ] 书名 ≤15 字，含 1 个热搜词
- [ ] 简介 ≤150 字，写完困境 + 金手指 + 目标，末句留悬念
- [ ] 前 300 字内出核心冲突，第 1 章亮金手指
- [ ] 主引擎能支撑"3 章一小爽、10 章一大爽"

细纲层（每章）：

- [ ] 单章目标字数落在 1800–3500（默认 2000–3000）
- [ ] 填了「开篇抓手」：本章前 300 字要写什么
- [ ] 填了「本章爽点」：类型 + 具体兑现方式
- [ ] 本章爽点类型与前后章不重复
- [ ] 有章末钩子，类型不与上一章重复
- [ ] 「本章事件」能一句话说清，且是具体动作、短句
- [ ] 全章没有"氤氲/斑驳"类文青词堆砌

机检命令（番茄档位会在读 `style.json` 后自动加严）：

```bash
python scripts/check_outline.py ./项目目录 --strict
```
