# 全书与卷级结构方法

本文件供 L1（全书大纲）、L2（人物设定）与 L3（卷纲）阶段参考。L4 细纲写法见 `chapter-outline-guide.md`。

---

## 一、四级结构的职责边界

| 层级 | 只回答 | 不回答 |
|---|---|---|
| L1 全书大纲 | 卖什么、靠什么引擎跑、分几卷 | 具体每章写什么 |
| L2 人物设定 | 谁在推动、凭什么推动、怎么说话、怎么变 | 每章的场景分解 |
| L3 卷纲 | 这一卷的目标、障碍、起伏、卷末兑现 | 每章的场景分解 |
| L4 细纲 | 每章的事件、变化、场景、钩子、伏笔 | 正文句子怎么写 |

跨层的错误最伤结构：在 L1 里写章节细节、在 L4 里改全书设定，都要退回本层。
人物的问题最容易串层：觉得"某一章主角行为不对"，往往其实是 L2 的人物卡没立住。

---

## 二、从点子到故事引擎

按下面顺序推，不要跳：

1. **一句话**：谁 + 什么处境 + 想做什么 + 最大阻力 + 赌注
2. **卖点**：读者只能从这本书拿到的东西（设定新奇 / 情绪代偿 / 智性快感 / 关系张力）
3. **引擎**：能不断产出事件的机制。判据——能不能从同一个引擎里连续取出 30 个不重复的事件
4. **循环**：触发 → 主角行动 → 反噬 → 升级。一轮约几章，写清楚
5. **赌注阶梯**：每卷赌注必须上一级，不能原地打转

引擎的三种常见形态：

- **外部驱动**：追捕、限期、任务链、赛季/大会
- **关系驱动**：身份错位、结盟与背叛、多方博弈
- **成长驱动**：解锁体系、收集、阶段晋级

好引擎通常同时含两条，一条主、一条辅。

## 三、全书骨架的三种排法

### 1. 三幕（最稳）

- 第一幕（约 25%）：建立处境、点燃事件、主角被迫上路
- 第二幕（约 50%）：不断升级的对抗，中点发生反转，结尾陷入最低谷
- 第三幕（约 25%）：绝地反击、高潮、余味

### 2. 四幕 / 四卷（网文常用）

卷 = 幕。每卷结构复用它自己的一套"起承转合"。适合 30-60 万字的中长篇。

### 3. 节拍表（校对用，不必逐条照搬）

| 位置 | 节拍 | 本书对应章节 |
|---|---|---|
| 1% | 开场画面：主角的日常与缺口 | |
| 10% | 催化剂：打破日常的事件 | |
| 20% | 争论与踏入：主角决定上路 | |
| 25% | 第二幕开始：进入新世界 | |
| 50% | 中点：假胜利或假失败，赌注翻倍 | |
| 75% | 一切失去：最亲近的支撑崩塌 | |
| 75-80% | 灵魂暗夜：主角认清自己 | |
| 80-99% | 终极对决 | |
| 99-100% | 终场：新常态与余味 | |

## 章级小循环（Story Circle）

`需要 → 出发 → 搜索 → 找到 → 付出代价 → 带着变化返回`

用于单章或单卷的自检：如果一章只走完"需要 → 出发"，读者会觉得没推进。

---

## 四、分卷与卷末兑现

分卷不是按字数切，而是按**局面变化**切。

每一卷必须有：

1. **本卷任务**——主角明确要达成/摆脱的东西
2. **最大障碍**——持续制造麻烦的人或力量
3. **卷末兑现点**——卷末局面发生的不可逆变化，必须在大纲里提前登记
4. **代价**——主角为赢必须付出的东西

验收提问：把这一卷删掉，后面的故事还成立吗？成立 → 这一卷是过渡卷，重做。

卷与卷的接缝处必须是"变化"，不是"休息"。

## 五、爽点与压抑配比

网文节奏参考值（按单章 3000 字计）：

| 项目 | 频率 |
|---|---|
| 小爽点 | 每 1-3 章一次 |
| 中爽点 | 每 10 章左右 |
| 大爽点 / 阶段胜利 | 每卷一次（卷末） |
| 章末钩子 | 每章必有 |
| 压抑段 | 不超过 5 章必须开始还款 |

原则：

- 爽点要"结账"——写清代价、后手、反噬，禁止白捡式碾压
- 压抑是为了抬爽点，压抑本身不给读者回报就不叫压抑，叫劝退
- 不允许连续同样类型的爽点（连打脸三次会腻）

## 六、前 20 章黄金区规划法

先把前 20 章排出来，再反推全书其余部分。

- 前 3 章：主角处境 + 第一次真正的冲突 + 卖点露头
- 前 10 章：核心关系/班底成形，第一个清晰的可追求目标
- 前 20 章：完成第一个完整的小循环（提出问题 → 解决 → 留下更大的问题）

前 20 章的章纲颗粒度要比后面细：写清每章的具体事件与钩子。

---

## 七、反派与配角设计

- **反派**：从他的视角看行为必须合理；与主角共享同一个"伤口"时最有张力；至少有一次让读者动摇"也许他是对的"
- **配角**：每个人都有自己要的东西，不是主角的说明书；配角要有自己的时间线，在主角看不到的地方也在动
- **工具人自查**：如果某个配角删掉后剧情毫无影响，要么给他自己的诉求，要么合并进别的角色

---

## 八、从结局倒推（防写飞）

写完 L1 后做一次倒推：

1. 写出最终章的局面
2. 反推：为了到达这里，倒数第一卷必须完成什么
3. 再反推前一卷……
4. 一直倒推到第一卷

任何一步接不上，说明大纲里缺一节桥。补在缺失的那一层，不要在细纲里硬圆。
