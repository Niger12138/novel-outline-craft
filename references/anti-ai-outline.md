# 结构层去 AI 味

本文件管**大纲/细纲字段里的 AI 腔**，不管正文句子。
正文层的去 AI 味交给 `de-ai-flavor` 与 `cn-novel-craft`（那里面有 34 种 AI 痕迹清单与量化门禁）。

理由：大纲阶段的 AI 味会一路带进正文，而且更难改——正文能润色，结构烂了只能重做。

---

## 一、大纲层的 8 种 AI 味症状

| # | 症状 | 长相 | 为什么致命 |
|---|---|---|---|
| 1 | **概括型节点** | "主角陷入内心的挣扎""两人关系变得微妙" | 没有事件，写手拿到只能自己编 |
| 2 | **情绪代替变化** | "本章变化：他感到很痛苦" | 情绪不是变化；变化是局面、权力、关系、认知的位移 |
| 3 | **排比堆砌** | "他失去了朋友，失去了财富，失去了信仰" | 三段并列是 AI 的默认节拍器 |
| 4 | **强行升华** | "这一刻，命运的齿轮开始转动""他终于明白了" | 替读者下结论，把悬念提前消费掉 |
| 5 | **对称强迫症** | 卷名全四字对仗、章标题全同构、每章张力值一样 | 真人的节奏是起伏的，平均即失真 |
| 6 | **抽象钩子** | "他看到一个意味深长的眼神""空气中弥漫着不安" | 钩子必须是具体事件，否则勾不住人 |
| 7 | **万能形容词人设** | "城府深沉""亦正亦邪""性格复杂" | 这等于没写；人物卡七问就是解药 |
| 8 | **名词化设定堆砌** | 一段话里全是专名与概念，没有一个动作 | 设定要绑定事件，绑不上的删 |

## 二、ban 词表（结构字段中零容忍）

在大纲、人物设定、卷纲、细纲的**任何字段**中出现即算问题（机检项）：

```
命运的齿轮 / 宿命感 / 宿命的 / 命运的 / 不禁 / 不由自主 / 下意识
与此同时 / 内心深处 / 五味杂陈 / 意味深长 / 气氛变得 / 空气中弥漫
这一刻他终于 / 他明白了 / 不知不觉 / 林林总总 / 氤氲 / 弥漫着
```

warn 级（大纲里出现说明在写正文而不是写结构）：

```
仿佛 / 似乎 / 好像 / 宛如 / 隐隐 / 复杂 / 微妙 / 无法言说
```

## 三、改写对照表

左边是 AI 味写法，右边是可直接落地的写法。原则：**把抽象换成动作，把总结换成事件，把情绪换成位移。**

| AI 味 | 改写成 |
|---|---|
| 主角陷入内心的挣扎 | 主角把已经签好的退婚书又撕了 |
| 他失去了所有 | 他的马被牵走，账房换成了别人的人 |
| 命运的齿轮开始转动 | 当夜，崔良请了三个月的假 |
| 气氛变得微妙 | 两个人都不说话，茶凉了没人续 |
| 意味深长的眼神 | 老朝奉把假当票翻到背面，指给他看 |
| 角色城府深沉 | 他从不先开口，别人问他话，他先笑一下再答 |
| 关系变得复杂 | 他替她挡了一次罚，但她哥哥那次是被他举报的 |
| 本章变化：他更成熟了 | 本章变化：认知——他终于确认父亲签过那份底账 |

## 四、去 AI 味的四条结构级硬规则

1. **每个字段必须能落到具体动作**
   把"本章事件"念一遍，如果念完手上还是空的，就是没写。
2. **"本章变化"必须命中四类之一**
   局面 / 权力 / 关系 / 认知。命中不了的章，等于没推进。
3. **钩子不许用抽象感受词**
   意味深长 / 不安 / 微妙 / 复杂 / 说不清 一律不许出现在钩子内容里。
4. **禁止平均**
   章标题不连章同构；张力值不连章相同；钩子类型不连章重复；卷长不强行对齐。

## 五、机检与人工的分工

| 项 | 谁查 |
|---|---|
| ban 词命中 | 机检（`check_outline.py`） |
| "本章变化"缺四类关键词 | 机检 |
| 章标题连章同构 | 机检 |
| 钩子套话 | 机检 |
| 节点是否真有事件 | 人工追读：把每个节点念一遍 |
| 人物是否有独立诉求 | 人工对照 `characters.md` 七问 |
| 卷末是否真兑现 | 人工追问：删掉这卷，后面还成立吗 |

机检过不了不动手写正文；人工项按 `diagnosis.md` 逐条走。

---

## 六、和正文层去 AI 味的分工

- 本层（结构）：保证大纲里没有概括、升华、抽象钩子、万能形容词——即**不给 AI 腔留入口**
- 正文层（`de-ai-flavor` / `cn-novel-craft`）：处理句式、破折号、对话标签、情绪命名、ban 词密度——即**写完之后擦痕迹**

两层都要过。只做正文层，等于在烂结构上做精装修。
